# Vehicle Registration System

## 📌 Project Description

Vehicle Registration System is a simple Java and Hibernate project.

This project is used to store and manage vehicle registration information in a MySQL database.

The project performs basic CRUD operations:

* Save vehicle data
* Get vehicle data by ID
* Update vehicle data
* Delete vehicle data

## 🛠️ Technologies Used

* Java
* Hibernate ORM
* JPA
* MySQL
* Maven
* Git & GitHub
* Eclipse IDE

## 🚗 Vehicle Information

The system stores the following vehicle details:

* Vehicle Type
* Vehicle Model
* Vehicle Color
* Number of Passengers
* Date of Purchase
* Registration Number
